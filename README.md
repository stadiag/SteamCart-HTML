# SteamCart-HTML

Version 100 % HTML + Tailwind CSS (CDN) de SteamPy : ouvrez `index.html` dans un navigateur.

- Ajout par ID ou URL Steam, import/export `.txt`, cases à cocher, thème sombre, devise au choix, totaux et économies (DLC inclus).
- **CORS sans serveur** : l'API Steam n'autorise pas le CORS, les requêtes passent par des proxys publics (corsproxy.io, allorigins, codetabs) avec bascule automatique.
